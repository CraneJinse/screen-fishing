# 第一次下载与游玩

1. 打开 https://github.com/CraneJinse/screen-fishing/releases/tag/v1.10.2 。
2. 在 Assets（附件）中点击 **ScreenFishing-1.10.2-windows-x64.zip**，约200 MB。Source code 是源码，普通玩家无需下载。
3. 将压缩包完整解压到自己的可写文件夹，例如桌面“摸鱼搭子”；不要只取出一个EXE，也不要在压缩包里直接运行。
4. 双击 **ScreenFishing.exe**。这是“摸鱼搭子”的启动程序；不需要安装Node.js或注册游戏账号。
5. 右键人物/船，点击“抛竿”。信息面板可从右键菜单或 Ctrl+Shift+F 打开。
6. 退出时使用系统托盘菜单；关闭信息面板只会隐藏面板。

## 更新与反馈

更新前退出游戏，备份旧程序旁边整个 user-data 文件夹。完整解压新版后，把备份的 user-data 放在新版 ScreenFishing.exe 旁边，再启动。

遇到问题请前往 https://github.com/CraneJinse/screen-fishing/issues ，选择 New issue 并描述版本、系统和复现步骤。不要公开个人存档或含敏感信息的截图。

此版本为Windows x64公开测试版，未提供安装器、自动更新或代码签名。
