# 1.9.4 公开测试版发布前测试方案

本轮范围：当前 Windows x64 纯钓鱼版本；本地测试与整理公开源码候选目录（自有代码MIT、素材单独声明），不上传 GitHub、不改玩家存档。

## 1. 冻结与隔离

确认版本、152物种/4鱼包/60事件/71成就及当前默认设置。所有写入测试使用临时目录或新建模拟状态。现有玩家进度仅作保护对象。运行日志留在本地，公开报告移除绝对用户路径和私人存档。

## 2. 新档成长与完成时间

1. 从0金币、0图鉴、0事件、0成就、仅F1开始。
2. 使用带固定种子的随机数和当前真实概率模块、尺寸/价格/保底/成就规则；记录算法、样本量及随机种子以便复跑。
3. 及时收杆，出售未锁定鱼，首次纯金/炫彩保留；攒够金币依次买F2/S1/S2。
4. 主动切换淡水/咸水追踪尚未完成的图鉴。分别记录解锁第2/3/4包、152物种、60事件、71成就的上钩次数、成功鱼获、模拟用时。
5. 报告P10/P50/P90、均值、极值及未完成样本；不把虚拟时间说成实际连续试玩。
6. 用真实状态机验证模拟器，检查动画时长、5–20秒等待、1%随机脱钩、30秒超时和10秒结果卡的计算边界。
7. 另测不出售、不切水域、错过20%上钩、保留全部鱼等行为；说明无法自动完成的主动操作（四角抛竿、卖鱼、购买/切水域）。

## 3. 规则与边界

运行全量单元测试和概率/尺寸/资产门禁。重点覆盖：全部71成就阈值与旧档迁移；四角宽容范围；三档异色保底；特殊事件3–7上钩间隔和重复保底；重复提交不重复入库；空杆/超时不扣进度；买包前置与余额；锁定与批量销售；历史1000条与大库存。

## 4. 存档与便携行为

新档首次启动、正常退出重启、主档损坏回退备份、主备均损坏保护、只读/写入失败提示、旧档迁移、单实例、重启中间状态、便携目录移动与包含空格中文路径。验证公开包无用户存档且首次启动确实从0开始。

## 5. 窗口和页面

桌宠右键菜单、拖动、置顶、显示/隐藏、快捷键、鱼获卡自动消失与点击、首次面板普通/隐藏启动/慢加载/失败恢复。图鉴、仓库、历史、商店、成就、特殊事件和设置的导航、筛选、搜索、排序、空数据、关闭重开。多个窗口尺寸下检查换行、溢出、控件重叠。检查锦鲤托盘/任务栏资源与全部事件/成就图。

## 6. 稳定性与资源

运行至少15分钟钓鱼循环压力测试，记录异常、窗口数量、内存样本与存档一致性；该结果只代表本机短期测试，不替代数小时/不同GPU/不同Windows版本兼容性验证。

## 7. 文档与发布目录

从程序真源更新百科，核对版本、首页8入口、移除称号UI、概率V3、71成就、10秒结果卡及首次显示修复。建立玩家README、更新日志、反馈模板、隐私与存档说明、第三方声明、测试报告与校验和。

GitHub源码仓库与Release附件分目录；便携ZIP放Release附件。仓库包含当前运行源码、必要素材、测试和说明；便携包包含运行代码与Electron依赖。均排除开发node_modules、个人存档、历史备份、聊天记忆、临时日志和私人路径。检查运行引用完整、依赖许可文件完整和压缩包哈希。

## 8. 验收标准

阻断问题必须修复并重测；模拟器与实际状态机偏差必须解释或纠正。每项注明通过/失败/未覆盖及证据。用户已确认首次面板问题解决；本轮原生鼠标、真实多屏、系统版本矩阵若受环境限制，明确保留人工复验项，不能标为通过。发布动作与软件/美术授权范围由用户后续决定。
