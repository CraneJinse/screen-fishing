# 1.12.2 发布验证报告

## 结论

1.12.2 已通过本机发布门禁，可以作为 Windows x64 公开测试版发布。运行包不含个人 `user-data`，升级仍需用户先退出旧版并自行备份、迁移完整存档目录。

## 覆盖范围

- 项目源码：298 项测试全部通过；语法检查、文档一致性、概率验证和 Electron smoke 通过。
- 公开源码：272 项可复现测试全部通过；`npm ci` 未发现依赖漏洞；300 次真实状态机与紧凑模拟器逐步一致。
- 响应式界面：14 个面板页面覆盖 480、640、800、960、1000、1280 像素宽度，共 84 种布局；195 张结果卡无溢出。仓库在 480、800、960 像素宽度滚动时，页头始终遮住排序控件、下拉菜单和卡片角标。
- 装备与概率：自动抛竿的购买、默认开启、设置关闭、正常收杆续抛及提前收杆不续抛均通过；三档钓饵按顺序购买、互斥装备，并只影响下一杆的稀有度与异色概率。
- 完整运行包：三窗口加载、三组快捷键、22 组主体动作、152 种鱼、608 个颜色模板、60 项特殊事件、71 项成就和三位内置角色均通过运行时检查。
- 存档安全：全新存档、正常旧档、主档损坏回退和主备均损坏阻止覆盖四种场景通过；ZIP 内容检查确认没有 `user-data`、`.git` 或开发依赖。
- 分发校验：公开源码构建的 ZIP 含2943个归档条目，2870个解包文件逐项哈希一致；带空格中文路径解压启动、EXE 锦鲤图标与产品名检查均通过。

## 1.12.2 专项结果

鱼获或特殊事件触发新成就后，结果窗口会先完整展示本次收获，再按成就册顺序逐张显示成就卡，每张保留10秒。旧存档不会重放既有成就；鱼获可抢占正在展示的成就并将其放回队首；隐藏桌宠时队列暂停，恢复后继续。最长成就条件、手动关闭和连续解锁均通过真实 Electron 验证。

仓库页滚动时，吸顶页头继续使用独立层叠上下文；窄窗口换行后，排序按钮和金币区域仍在边界内。图鉴、历史、商店、特殊事件、成就、角色库、设置和帮助页未发现同类越界或遮挡。

自动化覆盖不能替代所有实体设备组合。公开测试阶段仍建议重点收集多显示器、非整数 Windows 缩放、低性能 GPU、长期托盘驻留和安全软件误报的用户反馈。
