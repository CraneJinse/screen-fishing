# 存档、退出与隐私

运行包在程序同目录 user-data/ 保存游戏、窗口设置和必要的启动诊断；主存档有 .bak 备份。关闭信息面板只隐藏窗口，完整退出使用系统托盘菜单。隐藏桌宠和系统暂停会冻结剩余计时，不扣金币、鱼获或收藏。

更新/移动：先退出，备份整个 user-data/，完整解压新版，再复制存档文件夹。不要覆盖仍在运行的游戏。游戏内导入会改变本机进度，应先备份。文件损坏时优先让程序尝试备份恢复；主备均不可读时不会静默写入空白档。

本游戏无需账号或网络服务，不实现云同步、遥测或自动更新。不采集其他窗口内容、键盘文字或屏幕。快捷键仅用于指定操作。问题反馈请提供版本、Windows版本、复现步骤；如提供存档/截图，请先检查是否包含个人信息。不要把 user-data/ 放进 GitHub。
